# Finora

**Understand your money. Grow your business.**

Finora adalah platform keuangan dan operasional berbasis AI untuk UMKM,
usaha kuliner, toko retail, dan bisnis skala kecil-menengah.

Pemilik usaha cukup memfoto struk atau mengirim transaksi lewat WhatsApp.
Finora mengolahnya menjadi laporan keuangan, perhitungan HPP, analisis stok,
dan rekomendasi bisnis.

## Repositori

- [finora-web](https://github.com/finora-id/finora-web): aplikasi web (Next.js)
- [finora-api](https://github.com/finora-id/finora-api): backend dan worker
- [finora-docs](https://github.com/finora-id/finora-docs): PRD, arsitektur, dan API spec
